# NIAZ NET — Global Slideshow Standard

Mandatory for every NIAZ NET page and locale.

## Canonical frame
- Exact image canvas: **1944 × 809 px** (the homepage reference frame); every page and locale uses the same 1944:809 aspect ratio.
- Every slide is a PNG on that exact canvas. Verify source dimensions before release.
- Preserve complete artwork: scale proportionally with contain; never crop, stretch, or change its content.
- Fill any unused canvas with NIAZ NET navy (#061A36).
- Keep uploaded originals intact in their named folders under images/; the shared manifest references those files directly.
- The frame size and aspect ratio stay consistent across pages because the uploaded artwork uses the same canvas. The number of slides changes per folder; it must never be forced to a fixed site-wide number.

## One shared implementation
- Behavior/controller: /hero-slideshow.js.
- Visual/global UI rules: the niaz-slideshow-standard block in /site-shell.js.
- The shared frame rule uses a deliberate high-specificity override so legacy page/service CSS cannot change slideshow height, aspect ratio, or image fitting.
- Exactly one .hero-showcase root per slideshow page.
- Each slide is a .showcase-image child containing its image.
- `images/slideshow-manifest.json` must list **every slideshow image in its corresponding folder**, in the intended numeric filename order. There is no fixed slide-count limit: 19 uploaded images means 19 slides; 2 uploaded images means 2 slides.
- The controller resolves the folder by the page route or its `data-slideshow` key, then renders the complete configured list. It records the active folder and actual slide count on the slideshow root.
- Navigation dots are generated from the actual number of images and become more compact for large slide sets. Automatic rotation runs only when there is more than one slide.
- Left/right arrows are prohibited and hidden globally. Dots, keyboard focus, touch swipe, timing, and reduced-motion behavior are shared and generated by the controller.

## Locale and content
- Corresponding language versions of a page use the same artwork in the same order.
- Artwork whose filename is explicitly marked `FA` is shown only on Persian-language pages; it is not displayed with Persian text on English or Turkish pages.
- Locale may change accessible labels and the locale-approved slide list only; it must not create a different frame, controller, CSS rule, control position, or behavior.

## Prohibited
No inline slideshow controllers, page-specific slideshow dimensions, object-fit: cover/fill, alternate arrow/dot geometry, or per-language slideshow CSS. Future changes go through the shared controller, global standard, and approved slide manifest.
