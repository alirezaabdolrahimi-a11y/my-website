# NIAZ NET — Global Slideshow Standard

Mandatory for every NIAZ NET page and locale.

## Canonical frame
- Exact image canvas: **1944 × 809 px**.
- Every slide is a PNG on that exact canvas.
- Preserve complete artwork: scale proportionally with contain; never crop, stretch, or change its content.
- Fill unused canvas with NIAZ NET navy (#061A36).
- Keep originals intact; normalized copies live in images/slides/.

## One shared implementation
- Behavior/controller: /hero-slideshow.js.
- Visual/global UI rules: the niaz-slideshow-standard block in /site-shell.js.
- The shared frame rule uses a deliberate high-specificity override so legacy page/service CSS cannot change slideshow height, aspect ratio, or image fitting.
- Automated validation checks that this override remains present; it also verifies the physical image dimensions and every page's shared controller references.
- Exactly one .hero-showcase root per slideshow page.
- Each slide is a .showcase-image child containing its image.
- Previous/next arrows, dots, keyboard focus, touch swipe, timing, and reduced-motion behavior are shared and generated by the controller.

## Locale and content
- Locale may change slide copy, accessible labels, and the approved slide list only.
- A language-specific request must never create a different DOM structure, controller, CSS rule, frame size, control position, or behavior.
- Corresponding language versions of a page use the same artwork in the same order. Approved Persian-only artwork may be inserted as a content-only slide without changing structure.

## Prohibited
No inline slideshow controllers, page-specific slideshow dimensions, object-fit: cover/fill, alternate arrow/dot geometry, or per-language slideshow CSS. Future changes go through the shared controller, global standard, and approved slide manifest.
